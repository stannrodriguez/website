# website

Personal site for Stephanie Rodriguez. Astro + TypeScript, deployed to GitHub Pages at https://stannrodriguez.github.io/website/.

```sh
npm install
npm run dev      # local dev server
npm run build    # type-check + static build to dist/
npm run deploy   # publish dist/ to the gh-pages branch
```

Content lives in `src/data/` (site info, projects). See [REBUILD_NOTES.md](REBUILD_NOTES.md) for design decisions and open TODOs.
