# website

Personal site for Stephanie Rodriguez, built with Astro and TypeScript and deployed to GitHub Pages at https://stannrodriguez.github.io/website/.

Requires Node 20.3 or newer.

```sh
npm install
npm run dev      # start local dev server at http://localhost:4321/website/
npm run check    # run Astro and TypeScript checks
npm run build    # type-check and build static site to dist/
npm run preview  # preview the built site locally
npm run deploy   # build and publish dist/ to the gh-pages branch
```

Content lives in `src/data/` (site info, featured work, and projects). Share images and icons are generated by `scripts/share-images.mjs`. See [REBUILD_NOTES.md](REBUILD_NOTES.md) for rebuild history and open TODOs.
